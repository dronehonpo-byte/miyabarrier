# @miyabarrier/dashboard

[Miyabarrier](https://github.com/dronehonpo-byte/miyabarrier) の判定ログを可視化する静的ページ。サーバー不要・外部通信なし。

## 使い方

`index.html` と `dist/dashboard.js` を、**保護対象サイトと同じオリジン**に置いて開きます。

```
https://example.com/miyabarrier-dashboard/index.html
```

`localStorage` はオリジンごとに分かれているため、別のオリジン（GitHub Pages など）から他サイトのログを読むことはできません。その場合は、サイト側のコンソールで

```js
JSON.stringify(Miyabarrier.getLog());
```

の結果をコピーし、ページ下部の「読み込み・書き出し」欄に貼り付けてください。

## 表示する内容

| セクション             | 内容                                                        |
| ---------------------- | ----------------------------------------------------------- |
| サマリー               | 総送信数、判定ごとの件数と比率、平均スコア、観測期間        |
| 日別の判定件数         | 判定ごとに積み上げた棒グラフ（記録のない日も 0 として表示） |
| しきい値シミュレーター | 過去のログを別のしきい値で再判定し、変化する件数を表示      |
| スコアの分布           | 10 ビンのヒストグラム。色は現在のしきい値での判定区分       |
| 多かった判定理由       | 理由ごとの出現回数（詳細部分を丸めて集約）                  |
| ページ別               | ブロック・確認になった送信が多いページ                      |
| 判定の記録             | 直近 50 件の一覧（即時ブロックには「即時」バッジ）          |

## しきい値シミュレーターについて

ログにはスコアが入っているので、しきい値だけを差し替えれば後追いで検証できます。`report` モードで溜めたログから、自分のサイトに合うしきい値を決めるのがこのツールの主目的です。

即時ブロック（ハニーポット）はスコアと無関係にブロックされるため、`hard` が立っている記録はどのしきい値でもブロックのままとして数えます。

## ビルド

```bash
npm run build --workspace @miyabarrier/dashboard
```

集計ロジックは `src/aggregate.ts` の純関数に分離してあり、`tests/aggregate.test.ts` でテストされています。
