デモを試す → 営業文を入れると止まります。保護前／保護後を並べて比較できます。 実サイトでの見え方 → 普通の会社サイトに 1 行だけ埋め込んだ状態。警告表示や送信できたときの見た目。 ドキュメント → 導入方法、しきい値の調整、NG ワードのカスタマイズ。 仕組み → 7 レイヤーの判定内容と、スコアの組み立て方。
Layers

7 レイヤーの多層防御

Layer 1ハニーポット — 人間には見えない罠と、改ざん検知つきトークン
Layer 2行動解析 — 経過時間、ポインタ／タッチ、入力速度、貼り付け
Layer 2.5自動化の痕跡 — webdriver、headless の UA、環境の矛盾
Layer 2.6「不自然な自然さ」 — 速度の変動係数、軌跡の直線度、打鍵間隔の量子化
Layer 3チェックボックス認証 — スクリプトからのクリックを見分ける
Layer 4営業文面判定 — 13 カテゴリ 243 語、正当な問い合わせ語は減点
Layer 6AI 生成文判定 — 文長のばらつき、丁寧表現の密度、崩れの無さ

「機械が送っているか」と「営業・勧誘の文面か」を独立して評価し、noisy-or で合成します。人が手打ちした営業メールも、文面が中立な bot も、どちらも止まります。
